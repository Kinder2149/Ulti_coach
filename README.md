# Ulti Coach — la méthode du club

Site de la méthode d'entraînement du club (ultimate frisbee), support de la
formation des entraîneurs.

## Le site

La page d'accueil et les supports sont dans le dossier [`docs/`](docs/).
Une fois GitHub Pages activé, le site est en ligne à l'adresse :

**https://kinder2149.github.io/Ulti_coach/**

| Page | Rôle |
|---|---|
| `index.html` | L'accueil — le hub de navigation |
| `diaporama.html` | Le diaporama projeté pendant la formation |
| `conducteur.html` | Le conducteur d'animation (guide du formateur) |
| `fil-rouge.html` | Le support complet gardé toute l'année |
| `fiches.html` | Les 2 fiches A4 à photocopier |
| `lexique.html` | Le vocabulaire commun du club |

## Ce qui n'est pas ici, volontairement

Les documents de travail internes — séances nominatives, document de saison,
playbook de compétition, notes de méthode — **ne sont pas publiés** (ils
contiennent des données nominatives de joueurs). Ils restent hors du dépôt via
`.gitignore`.
